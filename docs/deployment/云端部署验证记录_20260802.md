## 安全说明

- 首页、WebSocket 和 GET 查询接口公开用于比赛演示；PATCH 等修改接口仍使用 Nginx Basic Auth。
- `/api/v1/telemetry` 使用独立长随机设备令牌，未携带令牌的请求返回 401。
- 设备令牌仅保存于云服务器 `/etc/visionbridge/api.env` 和树莓派权限为 600 的运行环境文件，未写入项目源码。
- 网站访问凭据保存在 `99_私密配置_禁止提交`，禁止提交到公开仓库。
- 当前为 HTTP + IP + 8088 方案；雨云官方说明中国大陆服务器应使用域名建站，申请并备案域名后应补 HTTPS。
- 本次截图中暴露过的云服务器 SSH 密码应立即轮换；已停用的研华 DCCS 与工作流凭据也应在原平台撤销。

### 定位问题结论

手机定位由手机的 GNSS、网络定位、权限精度、遮挡和系统省电策略决定，服务器只接收并保存 App 提交的坐标，因此定位漂移通常不是服务器造成。新版通过多次采样择优和地图校正降低误差；若仍超过 50 米，应确认 Android 已授权“精确位置”，关闭对视桥的省电限制，并在开阔位置重新定位。
