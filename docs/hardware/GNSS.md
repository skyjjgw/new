# LC76G GNSS 接入

## 连接与数据

边缘 Agent 从串口读取 NMEA，默认依次尝试 `/dev/ttyUSB1`、`/dev/ttyUSB0`、`/dev/ttyACM0`、`/dev/ttyS0`、`/dev/ttyAMA0` 和 `/dev/ttyAMA10`。设备用户必须具备串口读权限，常见做法是加入 `dialout` 组后重新登录。

```bash
sudo usermod -aG dialout pi
```

## 坐标系

LC76G 原始定位通常是 WGS-84；高德地图展示使用 GCJ-02。当前 Agent 由 `GPS_COORD_SYSTEM` 声明输出坐标系，API 与客户端必须避免重复转换。上线前应在已知点核对地图偏移，而不是只检查是否有经纬度。

## 定位质量

- 首次冷启动需要开阔天空和足够搜星时间；
- USB 供电不足、串口接触不良和天线遮挡会造成位置跳变；
- 应同时记录卫星数、HDOP、定位时间和最近有效位置；
- 无有效定位时不得把默认中心点伪装成设备实测位置；
- 事件可冻结触发时坐标，普通心跳继续上报最新位置。

## 验收

1. 串口持续输出有效 NMEA；
2. Agent 状态为 `gps ok`，卫星数和 HDOP 合理；
3. 静止 2 分钟的位置漂移在场景允许范围内；
4. WGS-84/GCJ-02 转换方向正确；
5. 断开 GNSS 后状态降级，恢复连接后无需重启 Agent；
6. 云端显示的位置时间戳和设备时间同步。
